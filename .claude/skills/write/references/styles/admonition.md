# 様式リファレンス: admonition（MkDocs Material）

`config.style: admonition` の教材が使う読み替え表。**構造・順序・執筆ルールは writing.md と共通**で、コールアウトを MkDocs Material の admonition 記法に置き換える。/github-pages（MkDocs Material）で公開する教材向け。**本文中の絵文字は全廃する**。

> ⚠️ このファイルは fw-sync の更新対象（カテゴリ A）。プロジェクト固有の語の調整はここを直接編集せず、writing.md 側に上書きとして書く（カテゴリ B で保護される）。枠見出しの対応表は plain / admonition / zenn の3ファイルに同型で存在し、変更時は3枚 + writing.md のテンプレートを同期する。

## 枠見出しの対応表

🎯 ✨ 📌 🏃 ✅ 📖 の枠見出しは、絵文字なしのプレーン見出しにする（plain 様式と同一）:

| emoji 様式 | admonition 様式 |
|---|---|
| `## 🎯 このセクションで学ぶこと` | `## このセクションで学ぶこと` |
| `## ✨ まとめ` | `## まとめ` |
| `## 🏃 実践: [タイトル]` | `## 実践: [タイトル]` |
| `### 🏃 Step N: [タイトル]` | `### Step N: [タイトル]` |
| `## 🏃 やってみよう: [タイトル]` | `## やってみよう: [タイトル]` |
| `## 📌 [作業名]前の確認` | `## [作業名]前の確認` |
| `## ✅ 完成チェックリスト` | `## 完成チェックリスト` |
| `📖 **この Chapter の進め方**: ...` | `**この Chapter の進め方**: ...` |

**位置ルール（実行コードの目印）の読み替え**: 「打つのは 🏃 配下だけ」は「打つのは**実践見出し**（`## 実践:` / `### Step N:` / `## やってみよう:`）の配下だけ」と読む。

## コールアウトの対応表

| emoji 様式 | admonition 様式 |
|---|---|
| 💡 TIP・補足 | `!!! tip "ヒント"` |
| ⚠️ 注意・よくあるエラー | `!!! warning "注意"`（エラーメッセージ付きテンプレートは `!!! warning "よくあるエラー: [概要]"` に本文構造ごと収める） |
| 📝 ノート・前提知識 | `!!! note "補足"` / `!!! note "前提知識"` |
| 🔑 キーポイント | `!!! info "ポイント"` |
| 🧠 人格コラム | `!!! quote "現場での考え方"`（一人称。頻度は config.persona_frequency に従い、同型の反復をしない） |
| やってみよう末尾の ✅ 確認 | `!!! success "確認"` |

## 運用ルール

- **役割行（weave 教材のみ）**: `**入力**:` / `**実行**:` / `**読む例**:`（絵文字なし。plain 様式と同形）
- admonition の中身は **4スペース字下げ**（lint が 1〜3 スペースを検出する）
- 1 Section **3〜4個まで**・同種の連続配置をしない
- 折りたたみは `??? note "タイトル"`（`<details>` の代わり。長いコードの退避に使う）
- **OS 差の書き分け**はコンテンツタブを使う: `=== "macOS"` / `=== "Windows"`。ラベル表記は固定・並びは macOS → Windows・短い差はタブ化せずインライン併記・中身は4スペース字下げ（`content.tabs.link` でサイト全体のタブ選択が連動する）
- 図の挿入位置規約（/illustrate）で「🧠 ブロッククオートの直後」とある箇所は「`!!! quote` ブロックの直後・次の `---` の直前」と読み替える

## 機械チェック（lint）の挙動

- 絵文字は**全面禁止**（`emoji-forbidden` 🔴。HTML コメント内の 📸 撮影指示・verified スタンプは検査対象外）
- `admonition-indent`: `!!!` / `???` 直後の内容行の字下げが 4 スペース未満なら 🔴
- Section の必須構造は `## このセクションで学ぶこと` / `## まとめ` の見出しで判定する（🟡）
- broken-bold・sentence-bold・dash-char・code-fence-language・absolute-path は全様式共通
