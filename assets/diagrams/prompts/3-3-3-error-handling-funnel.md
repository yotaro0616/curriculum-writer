# 3-3-3-error-handling-funnel

**モデル**: pro | **アスペクト比**: 16:9 | **解像度**: 4k

## プロンプト本文

```
インフォグラフィック風の図（左から右への集約フロー）を作成してください。横長の画面を左・中央・右の3エリアで均等に使い、大きな余白を作らない構成にします。

【内容】
- 左エリア: 縦に積まれた4個のコントローラの箱（Controller 1〜4）。各箱から「例外」「検証エラー」と書かれた小さな紙片が右へこぼれ出る。上に「検証が散在」のラベル
- 中央エリア: それらの紙片が、横向きに置かれた大きな漏斗（左から受けて右へ絞る形）に吸い込まれる。漏斗に「@RestControllerAdvice（例外の集約窓口）」「1か所に集約」のラベル
- 右エリア: 漏斗の口から、形の揃った1枚の書類「統一エラーレスポンス（ErrorResponse）」が出てくる
- 左から中央、中央から右へ流れる矢印で全体をつなぐ

【スタイル】
- フラットなベクターイラスト風・インフォグラフィック。くっきりした塗りと線
- 背景は完全にフラットな純白(#FFFFFF)のみ。紙の質感・鉛筆風の陰影・かすれ・しみ・うっすらした模様を一切描かない
- 漏斗と整形後の書類は青(#3B82F6)とオレンジ(#F97316)、散らばる紙片はグレー寄り
- ラベルは日本語（@RestControllerAdvice, ErrorResponse 等の用語は可）
- 16:9 横長レイアウト。要素を左右いっぱいに広げ、大きな空白エリアを作らない
```
