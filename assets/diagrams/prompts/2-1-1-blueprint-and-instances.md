# 2-1-1-blueprint-and-instances

**モデル**: pro | **アスペクト比**: 16:9 | **解像度**: 4k

## プロンプト本文

```
横長の比喩インフォグラフィックを作成してください。

【内容】
- テーマ: クラス（設計図）から new で複数のインスタンス（実体）を作る。
- 左側に大きな青写真（設計図）を1枚描く。設計図のタイトルは「Task（設計図）」。図面の中に型付きのスロット欄を3行描き、各行にラベル「String title」「boolean done」「Long id」を記す。設計図そのものは空欄（データを持たない）。
- 設計図から右へ「new」と書かれた太い矢印が伸びる。
- 右側に、その設計図から作られた実体カードを3枚並べる。各カードは同じ枠組みで、中身だけが違う。1枚目「title=牛乳を買う / done=false」、2枚目「title=ゴミ出し / done=true」、3枚目「title=請求書 / done=false」。
- 中心メッセージ: 1枚の設計図から、いくつでも実体を作れる。
- 要素は7個以内に抑える。

【スタイル】
- フラットデザイン・インフォグラフィック風、青写真と実体カードのアイコン
- 白背景。設計図は青 #3B82F6、実体カードはオレンジ #F97316 のアクセント
- クリーンな線画、ラベルは日本語、文字は大きく最小限
- 16:9 横長レイアウト
```
