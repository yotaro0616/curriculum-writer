## プロンプト本文

```
技術解説用のメンタルモデル図を作成してください。

【内容】
- テーマは「DI コンテナ」を、部品を供給する倉庫番にたとえた図
- 中央に大きな箱（倉庫の棚）を1つ置き、その中に組み立て済みの部品（歯車型のオブジェクト）が整然と並ぶ。棚の上部にラベル「DI コンテナ」を1つだけ付ける（重複させない）
- 棚の中のいくつかの部品に「Controller」「Service」「Repository」のラベル
- 右側に、部品をはめ込む空きソケットを持ったオブジェクトを1つ置く。棚から矢印が伸び、ぴったり合う部品（強調色でハイライト）がそのソケットにカチッとはまる様子を描く。矢印のラベルは「注入」
- 「自分で作らず、コンテナが渡してくれる」という関係が一目で伝わる構図

【スタイル】
- フラットデザイン・インフォグラフィック風。影・グラデーション・写実表現は避ける
- 白背景(#FFFFFF)。基調色は #007396（ティール寄りの青）。注入される部品とその矢印のみ #ED8B00（濃いオレンジ）で強調
- クリーンなアウトライン線画。ラベルは指定したものだけ、日本語と英語の技術用語で、大きく読みやすく
- 16:9 横長レイアウト。要素は6個程度に絞る
- 指定したラベル以外の文字・記号・英単語は一切描かない。ロゴやマスコットも描かない
```
