```
比喩図（メンタルモデル）を作成してください。

【内容】
- 中央に、1 つの同じ成果物を表す箱を大きく描く。箱の上部に『JAR / Docker イメージ（同じ成果物）』のラベル。箱の左右の側面に、設定を差し込むための空のソケット（差込口）が 3 つずつ描かれている。
- 左側に『開発環境』の区画。そこから開発用の設定が、プラグの形で中央の箱の左ソケットへ差し込まれている。プラグのラベルは上から『環境変数』『プロファイル dev』『ローカル DB』。
- 右側に『本番環境』の区画。そこから本番用の設定が、プラグの形で中央の箱の右ソケットへ差し込まれている。プラグのラベルは上から『環境変数』『プロファイル prod』『シークレット』。一番下のシークレットのプラグだけは鍵の形にして、ラベルは『シークレット』のみとする。
- 下部に『同じ成果物に、環境ごとの設定を外から注入』『秘密はコードに焼き込まない』というキャプションを添える。

【スタイル】
- フラットデザイン・インフォグラフィック風
- 白背景、左（開発）は青（#3B82F6）、右（本番）はオレンジ（#F97316）のアクセントカラー、中央の成果物はニュートラルなグレー
- クリーンな線画、ラベルは日本語。JAR / Docker / dev / prod は英語のまま
- 16:9 横長レイアウト
```
