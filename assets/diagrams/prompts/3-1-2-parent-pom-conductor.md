## プロンプト本文

```
インフォグラフィック風の比喩図を作成してください。

【内容】
- 「親 POM」を、タクトを持つ指揮者に見立てる
- 指揮者の前に、楽団員のように整列した複数の「依存ライブラリ」の箱（4個ほど）。各箱には Spring MVC / JPA などのライブラリ名と「バージョン」のタグが付く
- 指揮者のタクト一振りで、全ての箱のバージョンタグが整合の取れた同じ値にそろう（調和した状態）。箱から指揮者へ向かう、きれいに揃った接続線で表現する
- 手前に、開いた設計図のような書類「pom.xml」を置き、そこから指揮者へつながる
- 「バージョン一括管理」という短いラベルを指揮者の上に添える
- 要素は 指揮者(親POM)1 + 依存の箱4 + pom.xml 1 程度に絞り、ごちゃつかせない

【スタイル】
- フラットデザイン・インフォグラフィック風。影・グラデーション・写実表現は避ける
- 白背景(#FFFFFF)。青(#3B82F6)基調、アクセントにオレンジ(#F97316)
- クリーンなアウトラインの線画。ラベルは読みやすい日本語（pom.xml 等の用語は可）
- 16:9 横長レイアウト
```
