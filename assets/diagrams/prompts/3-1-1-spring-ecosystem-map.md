```
インフォグラフィック風の鳥瞰図（アイソメトリックな街の地図）を作成してください。

【内容】
- 「Spring の街」を斜め上から見下ろしたアイソメトリックな地図
- 街の中心に大きな中核施設「DI コンテナ」（中央発電所のような建物）を置き、街全体へ動力（線）を供給しているように見せる
- 中心の周りに役割の異なる3つの施設を配置し、技術名と比喩ラベルを併記する:
  - 「Spring MVC ＝ Web 受付所」… 来訪者(HTTPリクエスト)を受ける受付の建物
  - 「Spring Data JPA ＝ データ倉庫」… データを保管する倉庫
  - 「Spring Security ＝ 警備所」… 門を守る警備の建物
- 街全体を半透明のドーム状の外枠「Spring Boot（お膳立て・自動設定）」がやさしく包み込む
- 要素は 中心1 + 施設3 + 外枠1 の計5つ程度に絞り、ごちゃつかせない

【スタイル】
- フラットデザイン・インフォグラフィック風。影・グラデーション・写実表現は避ける
- 白背景(#FFFFFF)。青(#3B82F6)を基調にオレンジ(#F97316)をアクセント
- クリーンなアウトラインの線画。ラベルは読みやすい日本語のみ（英語の技術名 Spring MVC 等は可）
- 16:9 横長レイアウト
```
