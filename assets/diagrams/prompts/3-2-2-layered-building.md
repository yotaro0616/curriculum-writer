# 3-2-2-layered-building

**モデル**: pro | **アスペクト比**: 16:9 | **解像度**: 4k

## プロンプト本文

```
インフォグラフィック風のアイソメトリック図（3階建てのビルの断面）を作成してください。

【内容】
- 3階建てのビルを斜めから見た断面図。上から順に3つの階を積む:
  - 上階「Controller ＝ HTTP の受付」… 来客(リクエスト)を受ける受付フロア
  - 中階「Service ＝ 判断する頭脳」… 業務ルールを考えるオフィス
  - 下階「Repository ＝ データ倉庫」… 地下の金庫(データベース)につながる倉庫フロア
- ビルの左側に下向きの矢印（リクエストが上階から下階へ降りる）、右側に上向きの矢印（データが下階から上階へ戻る）の往復を描く
- 一番下にデータベースの金庫アイコンを置き、Repository フロアとつなぐ
- 各階に責務ラベルを併記する

【スタイル】
- フラットデザイン・インフォグラフィック風。影・グラデーション・写実表現は避ける
- 白背景(#FFFFFF)。青(#3B82F6)基調、矢印や強調にオレンジ(#F97316)
- クリーンなアウトラインの線画。ラベルは日本語（Controller / Service / Repository は英語可）
- 16:9 横長レイアウト
```
