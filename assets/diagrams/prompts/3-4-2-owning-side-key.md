## プロンプト本文

```
インフォグラフィック風の比喩図（関連と鍵の在り処）を作成してください。

【内容】
- テーマ: 双方向の関連では「所有側」だけが外部キー（鍵）を持つ
- 左に「User（ユーザー）」の箱。右に「Task（タスク）」の箱を2つ（1人のユーザーが複数のタスクを持つ＝1対多が分かるように）。User と Task を関連の線でつなぐ
- Task 側に、物理的な鍵のアイコンを持たせ「user_id（外部キー）＝所有側」のラベルを添える
- User 側には鍵を持たせず「mappedBy（相手に任せる）」の札を添える
- 下に小さく、結合箱「中間テーブル（task_tags）」を介して「Tag（タグ）」と Task を多対多でつなぐ。結合箱は2本の鍵を持つ
- 要素を絞り、ごちゃつかせない

【スタイル】
- フラットデザイン・インフォグラフィック風。影・グラデーション・写実表現は避ける
- 白背景(#FFFFFF)。青(#3B82F6)基調、鍵やキーの強調にオレンジ(#F97316)
- クリーンなアウトラインの線画。ラベルは日本語（User/Task/Tag, user_id, mappedBy 等の用語は可）。崩れた読めない文字を入れない
- 16:9 横長レイアウト
```
