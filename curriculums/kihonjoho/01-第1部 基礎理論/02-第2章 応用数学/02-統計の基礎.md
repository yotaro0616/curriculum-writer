## A/B テストの結果は、なぜ「平均が違う」だけでは判定できないのか

Web 開発をしていると、トップページのボタンの色を A 案（青）と B 案（緑）で出し分け、コンバージョン率（CVR）を比較する A/B テストに出会うことがあります。集計結果を見ると、A 案の平均 CVR が `4.2%`、B 案が `4.6%` だったとします。

ここで「B のほうが高いから採用」と即断するのは危険です。日々の CVR には大きなばらつきがあり、`4.2%` と `4.6%` の差が偶然の揺らぎの範囲内なのか、それとも本物の差なのかを判定するには、平均だけでなく **ばらつきの大きさ** を測る必要があります。

ばらつきを定量化する道具が、本セクションで学ぶ **分散** と **標準偏差** です。そしてばらつきの考え方を一歩進めると、自然界の多くの現象が従う **正規分布** にたどり着きます。試験頻出のこれらの指標を、A/B テストや実際のデータ解析の現場をイメージしながら見ていきます。

## 代表値：平均・中央値・最頻値

データ全体を「だいたいこのくらい」と一言で表す数値を **代表値** と呼びます。代表的なものは 3 つです。

**平均** （mean、算術平均）: すべての値の合計を個数で割ったもの。最も馴染みがある代表値です。

```text
平均 = (x1 + x2 + ... + xn) / n
```

5 人のテストの点数が `60, 70, 80, 90, 100` なら、平均は `(60 + 70 + 80 + 90 + 100) / 5 = 80` 点です。

**中央値** （median）: データを小さい順に並べたときの真ん中の値。データ数が偶数なら中央 2 つの平均を取ります。

`60, 70, 80, 90, 100` の中央値は `80` です。`60, 70, 80, 90` のように偶数個なら中央 2 つの平均で `(70 + 80) / 2 = 75` になります。

**最頻値** （mode）: 最も多く出現する値。`60, 70, 70, 80, 90` なら最頻値は `70` です。

3 つの代表値を使い分ける理由は、データに **外れ値** （極端な値）がある場合に表れます。たとえば年収のデータで、平均が `1,000 万円` でも、それは少数の高所得者が引き上げているだけで、中央値は `400 万円` ということがあります。

| 代表値 | 強み | 弱み |
|---|---|---|
| 平均 | 計算が単純、すべての値を反映 | 外れ値の影響を強く受ける |
| 中央値 | 外れ値の影響を受けにくい | 個別の値の情報は失われる |
| 最頻値 | カテゴリデータでも使える | 連続値では同じ値が稀で求めにくい |

> よくある誤解: 「平均値」と「中央値」は同じになることもありますが、データの分布が非対称（左右どちらかに偏っている）な場合は大きくずれます。報告された「平均」が代表値として妥当かを判断するには、中央値も合わせて確認する習慣が重要です。

## ばらつきの指標：分散と標準偏差

代表値だけではデータの全体像が見えません。平均が同じでも、`78, 80, 82` のように集中している場合と、`30, 80, 130` のように散らばっている場合では、データの性質がまったく違います。この「散らばりの大きさ」を数値化するのが **分散** と **標準偏差** です。

**分散** （variance、σ²）の計算手順は次のとおりです。

1. 各値と平均との差（**偏差**）を計算する
2. 偏差を 2 乗する（プラスマイナスを消すため）
3. 2 乗した値の平均を取る

```text
分散 σ² = ((x1 − 平均)² + (x2 − 平均)² + ... + (xn − 平均)²) / n
```

`60, 70, 80, 90, 100`（平均 80）の分散を計算してみます。

```text
偏差 : -20, -10, 0, 10, 20
偏差² : 400, 100, 0, 100, 400
分散  : (400 + 100 + 0 + 100 + 400) / 5 = 200
```

ところが分散の単位は元のデータの単位を 2 乗したものになるため（点数なら「点²」）、直感的に解釈しにくいです。そこで分散の平方根を取ったものを **標準偏差** （standard deviation、σ）と呼びます。標準偏差は元のデータと同じ単位になります。

```text
標準偏差 σ = √分散
            = √200
            ≈ 14.14
```

つまり「平均から見て、典型的には ±14 点くらいばらついている」と解釈できます。

| データ | 平均 | 分散 | 標準偏差 |
|---|---|---|---|
| 78, 80, 82 | 80 | 約 2.67 | 約 1.63 |
| 60, 70, 80, 90, 100 | 80 | 200 | 約 14.14 |
| 30, 80, 130 | 80 | 約 1,666.67 | 約 40.82 |

平均は同じ `80` でも、標準偏差を比べるとばらつきの大きさが一目でわかります。

## 正規分布：自然現象が従う「釣り鐘型」

身長、テストの点数、測定誤差、Web サイトの応答時間など、自然界や社会現象の多くは **正規分布** （normal distribution、ガウス分布）と呼ばれる「左右対称の釣り鐘型」の分布に従うことが知られています。

正規分布の形は平均 `μ`（ミュー）と標準偏差 `σ`（シグマ）の 2 つで決まります。

<!-- TODO: 画像追加 - 正規分布の釣り鐘曲線（68-95-99.7 ルールを色分けで示す） -->

正規分布で覚えるべき重要な性質が **68-95-99.7 ルール** です。

| 範囲 | データが含まれる割合 |
|---|---|
| 平均 ± 1σ（標準偏差 1 個分） | 約 68% |
| 平均 ± 2σ | 約 95% |
| 平均 ± 3σ | 約 99.7% |

たとえば日本人男性の身長が平均 `170 cm`、標準偏差 `6 cm` の正規分布に近いとすると、約 `68%` の人が `164〜176 cm` の範囲に、約 `95%` の人が `158〜182 cm` の範囲に収まることになります。

このルールを使うと、A/B テストや製造業の品質管理で「平均から `3σ` 以上離れた値は、偶然では `0.3%` しか起きない異常値」と判定できます。実際、製造業の品質管理では **3 シグマ法** と呼ばれる管理手法が広く使われています。

> 補足: A/B テストで「有意水準 5%」「有意水準 1%」という基準を聞いたことがあるかもしれません。これは「偶然の揺らぎでこの結果が起きる確率が 5% 以下なら、本物の差と判定する」という考え方で、正規分布のすそ野の確率に基づいて設計されています。

## 相関係数：2 つの変数の関係を測る

データ分析では、2 つの変数の関係を調べたい場面が頻繁にあります。「広告予算が増えると売上は増えるか」「ページの表示速度が遅いと離脱率は上がるか」といった問いです。これを数値化するのが **相関係数** （correlation coefficient、`r`）です。

相関係数は `-1` から `+1` の範囲を取り、次のように解釈します。

| 相関係数の値 | 関係 |
|---|---|
| +1 に近い | 強い正の相関（一方が増えるとほぼ比例して他方も増える） |
| +0.7 程度 | 比較的強い正の相関 |
| 0 に近い | 相関なし（無関係） |
| -0.7 程度 | 比較的強い負の相関 |
| -1 に近い | 強い負の相関（一方が増えるとほぼ比例して他方が減る） |

たとえば、Web サイトの表示時間（秒）と離脱率（%）の相関係数が `+0.85` なら、「表示が遅いほど離脱率が高い」という強い関係があると言えます。

> よくある誤解: 「相関」と「因果」は別物です。アイスクリームの売上と水難事故の件数には強い正の相関がありますが、アイスクリームが事故を引き起こすわけではなく、「気温が高い」という第三の要因が両方を引き上げています。試験では「相関があるからといって因果があるとは限らない」という観点が問われることがあります。

## 度数分布とヒストグラム

データの分布を視覚的に把握する基本ツールが **ヒストグラム** （histogram）です。データを一定の幅（**階級**）に区切り、各階級に含まれるデータの個数（**度数**）を棒グラフで表現します。

たとえばあるサービスの応答時間 `100 ms` 〜 `500 ms` のログを集計し、`50 ms` 刻みでヒストグラムを描くと、応答時間が `150〜200 ms` に集中しているのか、それとも `400〜450 ms` にも山があるのか（**双峰分布**）が一目でわかります。

正規分布なら釣り鐘型、偏った分布なら左右非対称な形になります。実務では、ヒストグラムを描いてから「平均を使うか中央値を使うか」を判断するのが定石です。

## 要点

- 代表値は **平均** ・ **中央値** ・ **最頻値** の 3 つ。外れ値がある場合は中央値が頑健
- ばらつきの指標は **分散** （偏差の 2 乗の平均）と **標準偏差** （分散の平方根）
- **正規分布** の **68-95-99.7 ルール**: 平均 ±1σ に 68%、±2σ に 95%、±3σ に 99.7% のデータが含まれる
- **相関係数** は `-1`〜`+1` の値を取り、`+1` で強い正の相関、`-1` で強い負の相関、`0` で無相関
- **相関** があっても **因果** があるとは限らない（第三の要因が両者を動かしている可能性）
- **ヒストグラム** はデータの分布を視覚的に把握する基本ツール
