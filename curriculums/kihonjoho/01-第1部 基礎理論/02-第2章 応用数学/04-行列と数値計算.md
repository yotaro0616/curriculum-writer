## CSS の transform: matrix() は、なぜ「6 個の数字」で表現されるのか

CSS で要素を回転・拡大縮小・移動するときに使う `transform` プロパティ。最も汎用的な書き方が次のような `matrix()` 関数です。

```css
/* 例: 要素を 45 度回転させる CSS */
.box {
  transform: matrix(0.707, 0.707, -0.707, 0.707, 0, 0);
}
```

`6` 個の数字が並んでいますが、これは行列 **（matrix）** の値を表しています。CSS が裏側で行っているのは、要素の座標 `(x, y)` に対する行列の掛け算です。同じことが、画像処理ライブラリの拡縮・回転、3D CG、機械学習のニューラルネットワーク、そして物理シミュレーションでも行われています。

行列はコンピュータ・サイエンスの応用範囲が非常に広く、現代の GPU は「行列計算を超並列で実行する専用ハードウェア」とも言えます。本セクションでは、試験で問われる基本演算と、浮動小数点と組み合わさったときの誤差問題を見ていきます。

## 行列の基本：行と列の表

**行列** （matrix）は、数値を縦と横に並べた表のことです。横方向の並びを **行** （row）、縦方向の並びを **列** （column）と呼びます。`2 行 3 列` の行列は次のように書きます。

```text
A = | 1  2  3 |
    | 4  5  6 |
```

行列のサイズは「行数 × 列数」で表記し、上の例は「`2 × 3` の行列」となります。1 行だけの行列を **行ベクトル** 、1 列だけの行列を **列ベクトル** と呼びます。

行列の各要素は `a[i][j]` のように添字で参照します。`a[1][2]` は「1 行目、2 列目の要素」を意味し、上の例なら `2` です（数学では 1 始まり、プログラミングでは 0 始まりが多いです）。

## 加減算とスカラー倍

行列同士の **加算** と **減算** は、**同じサイズの行列同士** で、同じ位置にある要素同士を足し引きするだけの単純な演算です。

```text
| 1  2 |   | 5  6 |   | 6   8 |
|      | + |      | = |       |
| 3  4 |   | 7  8 |   | 10  12 |
```

サイズが違う行列同士は加算できません（試験で時々問われます）。

**スカラー倍** は、行列のすべての要素に同じ数値を掛ける操作です。

```text
        | 1  2 |   | 3   6 |
3 ×    |      | = |       |
        | 3  4 |   | 9  12 |
```

ここまでは表計算ソフトでの一括計算と同じ感覚で理解できます。難所は次の積算です。

## 行列の積算：行と列の内積

行列の **積** （matrix product）の計算は、加減算と違って独特なルールがあります。`A × B` を計算するとき、`A` の各 **行** と `B` の各 **列** の内積（対応する要素を掛けて足したもの）を、結果の対応する位置に入れます。

サイズの条件: `A` が `m × n`、`B` が `n × p` のとき、積 `A × B` は `m × p` の行列になります。**A の列数と B の行数が一致する** ことが計算可能の条件です。

```text
| 1  2 |   | 5  6 |   | 1×5+2×7  1×6+2×8 |   | 19  22 |
|      | × |      | = |                  | = |        |
| 3  4 |   | 7  8 |   | 3×5+4×7  3×6+4×8 |   | 43  50 |
```

1 行 1 列目の `19` は、`A` の 1 行目 `(1, 2)` と `B` の 1 列目 `(5, 7)` の内積 `1×5 + 2×7 = 19` です。

行列の積で特に重要なのは、**順序を入れ替えると結果が違う** 点です。

```text
A × B ≠ B × A   （一般に成立しない）
```

数値の掛け算 `2 × 3 = 3 × 2` とは違って、行列の積は **非可換** （non-commutative）です。試験では「行列の積の交換法則は成り立たない」がよく問われます。

> よくある誤解: 行列の積でサイズが合わない（`A` の列数 ≠ `B` の行数）場合は計算できません。たとえば `2 × 3` の行列と `2 × 3` の行列の積は定義されません。「同じサイズなら計算できる」と思い込まないことが重要です。

## 単位行列と逆行列

数値の世界では「`5 × 1 = 5`」のように、掛けても変化しない `1` という特別な数があります。行列の世界での `1` に相当するのが **単位行列** （identity matrix、`I`）です。対角成分が `1`、それ以外が `0` の正方行列で、`n × n` の単位行列を `In` と書きます。

```text
I3 = | 1  0  0 |
     | 0  1  0 |
     | 0  0  1 |
```

任意の行列 `A` に対して `A × I = I × A = A` が成立します。

数値の世界では「`5 × (1/5) = 1`」のように、掛けると `1` になる **逆数** が存在します。行列の世界で同じ役割を果たすのが **逆行列** （inverse matrix、`A⁻¹`）です。

```text
A × A⁻¹ = A⁻¹ × A = I
```

逆行列は、すべての正方行列に存在するわけではありません。**逆行列が存在する行列** を **正則行列** （regular matrix）と呼び、存在しないものを **特異行列** （singular matrix）と呼びます。特異行列を見分ける指標が **行列式** （determinant、`det(A)`）で、`det(A) = 0` のときは逆行列が存在しません。

逆行列は方程式の「割り算」のような働きをします。`Ax = b` という行列方程式を解くとき、両辺に左から `A⁻¹` を掛けて `x = A⁻¹b` と求められます。CSS の `transform` を元に戻したいときや、機械学習の線形回帰のパラメータ推定で、この考え方が使われます。

## 数値計算の誤差：情報落ちと桁落ち

行列計算は、要素が浮動小数点数（小数）の場合に **誤差が累積** しやすい性質があります。1-1-2 で学んだ浮動小数点数の限界が、行列の積算で何度も繰り返される過程で増幅されてしまうのです。

ここでは試験頻出の 2 つの誤差を改めて整理します。

**情報落ち** （loss of information）: 絶対値が大きく異なる数同士の加減算で、小さい方の値が事実上失われる現象。

浮動小数点数は「指数部 × 仮数部」で表現するため、絶対値の異なる 2 つの数を足し算するには、まず指数を揃える必要があります。このときに小さい方の数の有効桁が仮数部から押し出され、情報が失われます。

```text
例: 単精度浮動小数点数（仮数部 7 桁）での計算

  10000000.0 + 0.5
= 1.0000000 × 10^7 + 0.00000005 × 10^7
= 1.0000000 × 10^7   （0.5 の情報が桁数を超えて消える）
```

数値的には `10000000.5` が正しいはずですが、結果は `10000000.0` のまま変わらないという誤差です。

**桁落ち** （loss of significance）: 値がほぼ等しい 2 つの数の **引き算** で、有効桁が大きく失われる現象。

```text
例: 値がほぼ等しい数の引き算

  1.234567 − 1.234566
= 0.000001

有効桁が 7 桁から 1 桁に減ってしまった
```

これも結果の値そのものは正しいですが、続けて計算する場合に「有効桁が 1 桁しか残っていない」という精度の低下が問題になります。物理シミュレーションや科学計算では、桁落ちを避けるために計算式の順序を工夫する技術が発達しています。

| 誤差 | 発生条件 | 対処の方針 |
|---|---|---|
| 桁あふれ | 表現可能な範囲を超える | 倍精度を使う、適切な型を選ぶ |
| 丸め誤差 | 有限の仮数部で 10 進小数を表現できない | DECIMAL 型や整数を使う |
| 情報落ち | 絶対値が大きく異なる数の加減算 | 計算順序を工夫する |
| 桁落ち | ほぼ等しい数の引き算 | 数式を等価変形して引き算を避ける |

> 補足: 機械学習のニューラルネットワーク学習で「数値が `NaN` になる」「学習が発散する」という現象は、行列計算における誤差の蓄積と密接に関わっています。バッチ正規化や勾配クリッピングといった手法は、こうした数値安定性の問題に対処するために考案されました。

## 行列の応用：CSS・3D・機械学習

行列は試験頻出ですが、計算自体は機械的です。それでも応用範囲の広さを知っておくと、暗記の動機づけが高まります。

**2D / 3D 変換** : CSS の `transform: matrix()`、SVG の `transform` 属性、WebGL の頂点シェーダなど、画面上での回転・拡縮・移動はすべて行列の積算で表現されます。`6` 個の数値で 2D アフィン変換、`16` 個で 3D アフィン変換を表現するのが標準です。

**画像処理** : 画像のぼかし・シャープ化・エッジ検出などのフィルタ処理は、画像（ピクセルの行列）と **カーネル** （小さな行列）の畳み込み演算で実現されます。

**機械学習** : ニューラルネットワークの「層」は、入力ベクトルに対する重み行列の積算と活性化関数の適用の繰り返しです。GPU で行列演算を超並列に処理することで、大規模な学習が可能になっています。

これらの応用では、行列のサイズが数万 × 数万に達することも珍しくなく、効率的な計算アルゴリズムと数値安定性が現代のソフトウェア開発の重要な要素になっています。

## 要点

- 行列の加減算は **同じサイズ** の行列同士でしか計算できない
- 行列の積 `A × B` は **A の列数と B の行数が一致** するときだけ計算可能。**順序を入れ替えると結果が異なる** （非可換）
- **単位行列** `I` は対角成分が 1、それ以外が 0 の正方行列。`A × I = A` が成立
- **逆行列** `A⁻¹` は `A × A⁻¹ = I` を満たす行列。すべての正方行列に存在するわけではない（`det(A) = 0` だと存在しない）
- **情報落ち** は絶対値が大きく異なる数の加減算で小さい方が消える誤差
- **桁落ち** はほぼ等しい数の引き算で有効桁が大きく減る誤差
- 行列計算は CSS の `transform`、画像処理、機械学習など現代の Web 開発の至る所で使われる
